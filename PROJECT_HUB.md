## Proposed content lifecycle
1. Manuscript intake and source/evidence register.
2. Editorial review and version tracking.
3. Book layout and EPUB/PDF preparation.
4. Cover, metadata, ISBN/KDP and distribution records.
5. Audiobook and accessible reading formats.
6. Sales/distribution links and performance reporting.

## Integration principles
- Preserve original manuscript files and their source attribution.
- Keep publication metadata in a structured catalogue.
- Maintain one canonical copy of each approved manuscript.
- Separate draft, reviewed, approved and published states.
- Never store passwords, API keys or payment credentials in repository files.
